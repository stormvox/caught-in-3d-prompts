Bloby Part 3 — Connect Claude to Blender and make your own character

What this does: a step-by-step recipe plus the prompts from the video, so you can make your own character the same way.

Tip: if you do not want to connect anything, skip step 1. Claude can still write the scripts; you paste them into Blender's Scripting tab and press ▶ Run Script.

Step 1 — Give Claude a way to reach Blender (optional, "MCP")

Paste this into Claude:

I use Windows and Blender (version: [your version]). I want Claude to control Blender through an MCP
connection. Guide me step by step, one step at a time, and wait for my answer after each step:
1) which Blender MCP add-on/server to use, 2) how to install it, 3) how to start the connection inside
Blender, 4) how to add it to Claude, 5) a harmless test (for example, add a cube and move it).
If something fails, ask me for the exact error text and help me fix it. Do not skip steps.

Step 2 — Describe your character in plain words

Shape, colors and mood. Paste and fill in the brackets:

Write ONE Blender Python (bpy) script that builds a cartoon character from simple shapes only.
Character: a [animal/robot/monster] called "[NAME]". Shape: [round / tall / tiny legs ...].
Colors: [main color], [second color], [accent color]. Mood: [friendly / sleepy / excited].
Parts: [head, body, belly, big eyes, cheeks, arms, feet, 3 small tufts ...].
Name every object clearly and parent everything to one empty called "CharacterRoot".
Add a dark floor, two area lights (key + fill), a camera, smooth shading and glossy materials.
Render one vertical 1080 x 1920 still. Comment the code and tell me in 3 lines how to run it.

Step 3 — Ask for small changes, one at a time

Good examples:

  • "Make the eyes 20% bigger."
  • "Make the body color warmer."
  • "Give him a calmer, more relaxed pose. No big movements."

Step 4 — Check every result

Claude can make mistakes. Look at every render before you continue, and if something is wrong, say exactly what you see.

Look at this result. Tell me honestly what could be wrong (proportions, colors, overlapping parts,
objects floating in the air). Then give me the smallest possible fix.
