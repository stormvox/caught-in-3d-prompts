Bloby Part 1 — Build a cute cartoon character in Blender with Claude

What this does: gives you the exact prompt from the video. Claude writes a Blender Python script that builds a character like Bloby from simple shapes, adds colors, lights and a camera, and renders a picture.

You need: Blender (3.x–5.x) and Claude. Two ways to use it:

  • Easy: paste the prompt into Claude, copy the script it writes, open Blender → Scripting tab → New → paste → press ▶ Run Script.
  • Connected: if Claude is connected to Blender (MCP), tell Claude to run it for you.

The prompt (copy everything below)

You are an expert Blender Python (bpy) artist. Write ONE complete script that runs in Blender
(version 4.x or 5.x) and builds a cute cartoon mascot called "Bloby" from simple primitives.
Use only bpy and math. Start by clearing the scene.

Character (all sizes in Blender units, feet on the floor at z = 0):
- Body: UV sphere at (0, 0, 0.9), scale (0.75, 0.6, 0.9), glossy blue (0.15, 0.45, 0.95).
- Belly: UV sphere at (0, -0.45, 0.85), scale (0.5, 0.2, 0.6), light blue (0.35, 0.8, 1.0).
- Head: UV sphere at (0, 0, 2.15), scale (1.0, 0.9, 0.95), same blue as the body.
- Eyes: two white spheres at (-0.38, -0.78, 2.3) and (0.38, -0.78, 2.3), scale (0.3, 0.16, 0.34),
  with dark pupils at (±0.38, -0.9, 2.3), scale (0.15, 0.08, 0.2).
- Cheeks: two pink spheres at (±0.6, -0.72, 1.95), scale (0.16, 0.06, 0.1), color (0.9, 0.2, 0.35).
- Mouth: a small dark sphere at (0, -0.85, 1.85), scale (0.2, 0.06, 0.1).
- Arms: two purple spheres at (±0.95, 0, 1.05), scale (0.25, 0.25, 0.65), purple (0.5, 0.2, 0.85).
- Feet: two purple spheres at (±0.35, 0, 0.2), scale (0.3, 0.35, 0.3).
- Tufts: three small purple spheres on top of the head at (-0.25, 0, 3.1), (0, 0, 3.2), (0.25, 0, 3.1),
  scale (0.12, 0.12, 0.3).
- Name the objects clearly (Head, Body, Belly, Mouth, Arm, Arm.001 ...) and parent all parts to one
  empty called "CharacterRoot" so I can move the whole character.
- Smooth shading on every part. Use Principled BSDF materials with low roughness (about 0.35).

Scene:
- A dark floor plane and a soft dark-blue background.
- Two area lights: a strong key light from the front-right above (location 3, -4, 5, energy 600)
  and a weaker fill light from the front-left (location -4, -2, 3, energy 250).
- A camera that looks at the character from the front (focal length 50 mm), framing the whole body.
- Set the render engine to EEVEE, resolution 1080 x 1920 (vertical), and render one still image to
  the folder I give you.

Rules: no external files, no add-ons, comment each section, and tell me in 3 short lines how to run it.

How to get a better result (the "ask → look → fix" trick)

  1. Run it and look at the render.
  2. Ask for one small change at a time, for example: "Make the eyes 20% bigger", "Make the colors warmer", "Add a small smile".
  3. Always check every result yourself: Claude can make mistakes, and the first version is rarely perfect.
