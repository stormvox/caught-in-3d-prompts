Connect Blender to Claude or Antigravity (MCP setup prompts)

What this does: two copy-paste prompts that make your AI walk you through connecting Blender to Claude or Antigravity with an MCP server, one step at a time.

Safety: an MCP connection lets the AI run code inside Blender. Save your file first, only use servers you trust, and do not open the connection to other computers.

Option A: Claude (Desktop or Claude Code)

I use [Windows / macOS / Linux] and Blender [version]. I want you to control Blender through an MCP connection.
Guide me step by step, ONE step at a time, and wait for my answer after each step.
1) Check what I already have: Blender version, Python, and the "uv" tool (explain how to install uv if it is missing).
2) Tell me which Blender MCP server and which Blender add-on to use and give me the link to its README, so I can compare
   your steps with the official ones (they change over time).
3) How to install the add-on in Blender (Edit > Preferences > Add-ons) and how to start the connection from the add-on panel.
4) How to add the MCP server to [Claude Desktop / Claude Code] and how to restart it.
5) A harmless test: add a cube, move it, then delete it.
If a step fails, ask me for the exact error text and help me fix it. Do not skip steps.
Remind me to save my .blend file before the first command that changes my scene.

Option B: Antigravity

4) How to open Antigravity's MCP settings, add the server there (show me the exact JSON to paste) and refresh the list of tools.

If a step fails, ask me for the exact error text. Do not skip steps, and remind me to save my .blend file first.

Quick reference (one commonly used setup)

A widely used open-source Blender MCP is ahujasid/blender-mcp. At the time of writing it uses a Blender add-on plus the uvx blender-mcp command. The settings usually look like this (always compare with its README, because steps change):

{
  "mcpServers": {
    "blender": {
      "command": "uvx",
      "args": ["blender-mcp"]
    }
  }
}

Claude Code: claude mcp add blender -- uvx blender-mcp. Then in Blender press N, open the add-on tab and connect.
